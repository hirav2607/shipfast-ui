# shipfast-ui

UI for ShipFast — React + TypeScript (Vite) starter scaffold.

## Getting started

1. Install
```bash
npm install
# or
yarn
```

2. Run dev server
```bash
npm run dev
# or
yarn dev
```

3. Build
```bash
npm run build
# or
yarn build
```

4. Preview production build
```bash
npm run preview
# or
yarn preview
```

## What’s included

- Vite + React + TypeScript scaffold
- Basic Node CI workflow (GitHub Actions)
- MIT license
- .gitignore (Node)
- GitHub Project board recommended: "Shipfast UI" (kanban)
